# Network Monitoring System

This project is a real-time network monitoring system built using Python and Tshark.

## Features
- Captures live network traffic
- Detects abnormal traffic patterns
- Identifies possible DoS and port scan attacks
- Logs suspicious activity

## Tools Used
- Python
- Tshark (Wireshark CLI)

## How to Run
1. Install tshark
2. Run:
   python3 detector.py
